# Budget Desk 1.2.0

Download **BudgetDesk_v1.2.0_Windows.zip**, extract it to a new folder and open **BudgetDesk.exe**. Before updating, export a JSON backup from **Settings & backup** in your previous version.

- **Language and appearance.** Choose English, Ελληνικά or Čeština and Light or Dark in **Settings & backup**, then select **Save**. The changes apply immediately and the budget remembers them. Paused recurring cards stay red in both themes.
- **Timed payments.** New one-off plans automatically post at the scheduled local date and time. For a reminder you want to pay yourself, clear **Automatic recording**. Existing plans from earlier versions stay manual until you enable the option. Automatic recurring and one-off payments missed while the app was closed or the computer was asleep are recorded on return using the scheduled timestamp, once per occurrence. Manual payment uses the time of confirmation.
- **Offline manuals.** The **Manuals** folder contains English, Czech and Greek guides in PDF and HTML. The **Support** folder includes the test launcher, Windows test results and **IDEAS.md**.

The normal budget and **Support/Test-Sandbox.cmd** continue to use their existing, separate data folders.
